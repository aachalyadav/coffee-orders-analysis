# ☕ Coffee Orders Sales Analysis

## Overview
An end-to-end Excel project analyzing coffee sales data across multiple countries and customer segments. Manually cleaned the data and fill the null values also created the new column (feature engineering)

## Tools Used
- Microsoft Excel (Pivot Tables, XLOOKUP, Charts)

## Key Features
- Sales trend analysis over time
- Top customers by revenue
- Country-wise sales comparison
- Interactive dashboard with slicers

## Skills Demonstrated
- Data cleaning and transformation
- Pivot table design
- Dashboard creation in Excel
